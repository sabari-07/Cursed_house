# Assets and licensing

The project is open source (MIT) and is entered in a hackathon whose rules forbid
third-party material that the entrant has no right to use. Every asset must be
safe to redistribute.

## Allowed sources

- AI images generated by the project owner (ChatGPT). Note them as AI-generated.
- Public-domain works: old paintings on Wikimedia Commons (check the licence field
  reads "Public domain" or "CC0"), and U.S. National Park Service recordings.
- Pixabay (Pixabay Content License) and SoundDino (free for commercial use, no
  attribution required). Keep the source page URL for every file.
- Fonts under the SIL Open Font License (for example Creepster).

## Not allowed

- Images or sounds taken from games, films, music or brands (SoundDino also hosts
  ripped game sounds; do not use those).
- Anything with an unknown source.

## Every time an asset is added

1. Put it under `public/` with a descriptive name.
2. Add a row to the **Asset credits** table in `README.md`: file path, source
   (with a link), author if known, licence, and any edit made (trimmed, recoloured,
   figure painted out).
3. If the asset was edited by a script, keep the script's behaviour described in
   the credit, so the edit can be reproduced.
